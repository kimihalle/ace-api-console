模型接入

API 接入文档

登录工作台创建 API 密钥，从模型广场选择模型，再把接口地址、密钥和模型名称填进你使用的软件。

1. 登录工作台没有账户时，先从首页注册；若站点关闭注册，请联系管理员。
2. 创建 API 密钥打开「API 密钥」→「创建新密钥」，填写名称并选择调用分组。
3. 复制模型并配置从「模型广场」复制模型名称，再选择客户端支持的接口格式。
创建密钥时：调用分组为必选项；消费上限和到期时间可按需填写，留空分别表示不限制和永不过期。创建成功后请复制保存密钥，密钥列表会打码显示。

查询可用模型

用创建好的 API 密钥查询它当前可用的模型，再把返回的模型名称复制到请求里。不同账户和调用分组能使用的模型可能不同。

curl https://你的站点域名/v1/models \
  -H "Authorization: Bearer 你的访问密钥"

如果结果里没有目标模型，请检查工作台「模型广场」和创建密钥时选择的调用分组。

OpenAI 格式

如果软件里有「OpenAI」或「OpenAI Compatible」选项，按下面填写。API 地址使用本站域名后加 /v1；也可以登录工作台，在「API 密钥」页面复制「API 接入地址」。

接口格式OpenAI / OpenAI Compatible
API 地址https://你的站点域名/v1
API Key在「API 密钥」页面创建的密钥
模型名称工作台「模型广场」中显示的名称

命令行调用示例：替换站点域名、密钥和模型名称后再运行。

curl https://你的站点域名/v1/chat/completions \
  -H "Authorization: Bearer 你的访问密钥" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "控制台里的模型名称",
    "messages": [
      {"role": "user", "content": "你好"}
    ]
  }'

Claude 格式

只有软件明确提供「Anthropic API」或「Claude API」选项时，才用这一组设置；API Key 使用同一个工作台密钥。

接口格式Anthropic / Claude
API 地址https://你的站点域名
API Key同一个控制台访问密钥
模型名称工作台「模型广场」中显示的名称

如果软件要求填写「完整接口地址」，填写 https://你的站点域名/v1/messages。命令行示例：

curl https://你的站点域名/v1/messages \
  -H "x-api-key: 你的访问密钥" \
  -H "anthropic-version: 2023-06-01" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "控制台里的模型名称",
    "max_tokens": 512,
    "messages": [
      {"role": "user", "content": "你好"}
    ]
  }'

Gemini 格式

只有客户端明确支持 Google Gemini API 格式时，才用这一组设置。模型名称从工作台「模型广场」复制。

接口格式Google Gemini
API 地址https://你的站点域名
API Key在「API 密钥」页面创建的密钥
模型名称工作台「模型广场」中显示的名称

命令行调用示例：

curl https://你的站点域名/v1beta/models/控制台里的模型名称:generateContent \
  -H "x-goog-api-key: 你的访问密钥" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [
      {"parts": [{"text": "你好"}]}
    ]
  }'

Embeddings 和 Rerank

如果控制台已配置并向你的分组开放这类模型，可以使用下面的接口。没有对应模型或权限时不能调用。

生成文本向量

curl https://你的站点域名/v1/embeddings \
  -H "Authorization: Bearer 你的访问密钥" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "控制台里的向量模型名称",
    "input": "需要转换成向量的文本"
  }'

对候选文本排序

curl https://你的站点域名/v1/rerank \
  -H "Authorization: Bearer 你的访问密钥" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "控制台里的重排模型名称",
    "query": "要查找什么内容",
    "documents": ["第一段候选文本", "第二段候选文本"]
  }'

不知道怎么选？

看你正在使用的软件提供什么选项：有 OpenAI 就选 OpenAI；写着 Anthropic / Claude 就选 Claude；写着 Google Gemini 就选 Gemini。每种格式都要使用「模型广场」里完全相同的模型名称。

调用失败时

密钥错误：确认密钥完整、没有多余空格，并检查密钥是否已停用或过期。

模型不存在：回「模型广场」复制模型名称，不要凭印象输入。

没有权限或余额不足：检查账户余额、密钥状态和创建密钥时选择的调用分组。

Gemini 调用失败：确认客户端使用 Gemini 格式，模型名称没有多余空格，并且账户已开通该模型。

仍然失败时，在「使用统计」里查看调用记录。也可以把响应头里的 X-Oneapi-Request-Id 一并发给管理员，方便查找记录。不要发送访问密钥。

可用模型、模型名称和费用以工作台显示及调用记录为准。请妥善保管 API 密钥。
